# 掌阅在线阅读器排版美化

一款面向掌阅网页版（`pc.ireader.com`）的 Tampermonkey 用户脚本。它重新整理字体、字号、行距、段距、版心与阅读配色，并把掌阅混淆字形还原为普通汉字，让正文使用统一字体显示。

> 不修改电子书源文件，不上传阅读数据；设置只保存在当前浏览器。

## 主要功能

- **更舒服的正文排版**：预置思源宋体、霞鹜文楷、无衬线及系统字体，也支持自定义字体。
- **完整阅读参数**：调整字号、行高、字距、段距、版心宽度和页边距。
- **多种配色**：纸张、暖黄、护眼、夜间等主题，可继续微调文字和背景颜色。
- **混淆字形解码**：将掌阅字体中的私用区字形还原为普通汉字，避免正文混用两套视觉风格。
- **特殊页面保护**：识别封面、图片页、目录与正文，减少封面丢失、页码错位和目录断裂。
- **双渲染模式兼容**：同时处理 EPUB 沙箱 iframe 与直接写入主页面的正文。
- **EPUB 高度同步**：字体和行距重排后自动同步内页真实高度，避免章节末段被固定容器裁切。
- **动态章节适配**：翻页或切章后自动重新应用设置；按 `Alt + R` 可打开或关闭设置面板。

## 安装

1. 在浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 点击 [安装脚本](https://raw.githubusercontent.com/RoyLaw/ireader-reading-beautifier/main/ireader-reading-beautifier.user.js)。
3. 在 Tampermonkey 页面确认安装，然后打开任意掌阅网页版书籍。

脚本只匹配 `https://pc.ireader.com/reader/*`。右侧的 **Aa** 按钮用于展开设置；快捷键为 `Alt + R`。

## 混淆字形处理

部分掌阅书籍通过专用字体把常用汉字编码到 Unicode 私用区。浏览器因此必须混用该专用字体与用户字体，字重、字面和笔画风格会明显不一致。

本脚本在页面渲染后进行一对一字符还原，并保留原始内容：关闭“解码混淆字形”时可立即恢复。若掌阅更换字体版本或映射规则，可先关闭此功能并提交 Issue。

## 隐私与权限

- 不收集、上传或统计阅读内容。
- 不调用第三方服务。
- 不申请 Tampermonkey 特权 API（`@grant none`）。
- 个性化设置仅保存在网页本地存储中。

## 已知限制

- 掌阅调整网页结构或混淆字体后，个别书籍可能需要更新适配。
- 不同出版社的特殊版式差异较大；图片型正文不会被强制转换为文字。
- 字体是否可用取决于本机已安装字体，脚本会按预设顺序回退。
